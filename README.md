# EcoSort AI — เว็บวิเคราะห์ขยะจากภาพ

เว็บนี้ใช้ Gemini Vision API วิเคราะห์ภาพจริงจากกล้องหรือไฟล์ภาพ โดยไม่ต้องฝึกหรืออัปโหลดโมเดล Teachable Machine เอง

## สิ่งที่ต้องมีก่อนเปิดใช้งานออนไลน์
1. Google Gemini API key จาก Google AI Studio
2. บริการโฮสต์ที่รัน Node.js ได้ เช่น Render หรือ Railway
3. ตั้งค่า environment variable ชื่อ `GEMINI_API_KEY` ในหน้า Environment ของผู้ให้บริการโฮสต์

**อย่าใส่ API key ลงใน `app.js`, `index.html` หรือส่ง API key ในแชตสาธารณะ** ตัวอย่าง `.env.example` มีไว้บอกชื่อตัวแปรเท่านั้น

## วิธีรันบนเครื่อง
ต้องติดตั้ง Node.js 18 ขึ้นไป จากนั้นเปิด Terminal ในโฟลเดอร์นี้ แล้วรัน:

```bash
# ตั้งค่า API key ใน terminal (ตัวอย่าง macOS/Linux)
export GEMINI_API_KEY="YOUR_API_KEY"
npm start
```

บน Windows PowerShell:
```powershell
$env:GEMINI_API_KEY="YOUR_API_KEY"
npm start
```

เปิด `http://localhost:3000`

## วิธี Deploy บน Render (ตัวอย่าง)
1. สร้าง repository ใน GitHub และอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. เข้า Render แล้วสร้าง **New Web Service** เชื่อม repository
3. Runtime: Node; Build command: เว้นว่าง; Start command: `npm start`
4. เพิ่ม Environment Variable:
   - Key: `GEMINI_API_KEY`
   - Value: API key ของคุณ
5. กด Deploy และรอให้สถานะเป็น Live
6. เปิด URL ที่ Render สร้างให้ เว็บไซต์จะวิเคราะห์ภาพได้เมื่อ API key และโควตาพร้อม

## ความสามารถ
- เปิดกล้องมือถือ/คอมพิวเตอร์ (เว็บไซต์ออนไลน์ต้องใช้ HTTPS)
- ถ่ายภาพจริงหรืออัปโหลด JPG/PNG/WEBP
- ส่งภาพให้ Gemini วิเคราะห์และจัดเข้าหมวด รีไซเคิล / อินทรีย์ / ทั่วไป / อันตราย / ไม่แน่ใจ
- แสดงความมั่นใจ ถังที่แนะนำ คำแนะนำ และข้อควรระวัง
- มีการย่อภาพก่อนส่งเพื่อจำกัดขนาดคำขอ

## ข้อจำกัดที่ควรทราบ
- AI อาจจำแนกผิด โดยเฉพาะเมื่อภาพไม่ชัด วัตถุซ้อนกัน หรือมองไม่เห็นวัสดุ
- ค่า confidence เป็นค่าประเมินจากโมเดล ไม่ใช่การรับประกันความถูกต้อง
- การเรียก API อาจมีค่าใช้จ่ายหรือข้อจำกัดโควตาตามบัญชี Google
- เวอร์ชันนี้ยังไม่มีระบบสมาชิก ฐานข้อมูลประวัติ หรือคะแนนออนไลน์; ไม่ควรใช้คะแนนจากหน้าเว็บเป็นหลักฐานการทิ้งขยะจริง
- ควรตรวจสอบคำแนะนำของเทศบาล/หน่วยงานจัดการขยะในพื้นที่ก่อนทิ้งขยะอันตราย
